# **Complete Oracle 21c RAC to Data Guard Setup - Step by Step**

## **PHASE 1: PREPARATION & PLANNING**

### **1.1 Architecture Overview**
```
Your Setup:
PRIMARY: Oracle 21c RAC (2 nodes) with ASM
STANDBY: Single instance Oracle 21c (or RAC if you want)

Network Requirements:
- Primary SCAN: 192.168.1.100
- Primary Node1: 192.168.1.101
- Primary Node2: 192.168.1.102  
- Standby Server: 192.168.1.200
- Same OS, same Oracle version/patch
```

### **1.2 System Preparation**
```bash
# On ALL servers (Primary RAC nodes and Standby):
# Add host entries to /etc/hosts
sudo vi /etc/hosts

# Add these lines:
192.168.1.101   racnode1
192.168.1.102   racnode2
192.168.1.100   rac-scan.cluster.local
192.168.1.200   stdbysvr

# Test connectivity
ping -c 3 racnode1
ping -c 3 racnode2
ping -c 3 stdbysvr
```

## **PHASE 2: PRIMARY RAC CONFIGURATION**

### **2.1 Enable Archivelog Mode (on Primary)**
```sql
-- Connect to primary database from any node
sqlplus / as sysdba

-- Check current status
SELECT name, log_mode, database_role FROM v$database;

-- If not in archivelog mode:
SHUTDOWN IMMEDIATE;
STARTUP MOUNT;
ALTER DATABASE ARCHIVELOG;
ALTER DATABASE OPEN;

-- Enable force logging (CRITICAL!)
ALTER DATABASE FORCE LOGGING;

-- Verify
SELECT log_mode, force_logging, database_role FROM v$database;
```

### **2.2 Create Standby Redo Logs (SRL)**
```sql
-- Check current online redo log size
SELECT group#, thread#, bytes/1024/1024 MB FROM v$log ORDER BY thread#, group#;

-- Create Standby Redo Logs (SRL)
-- Rule: (max logfiles per thread + 1) * threads
-- Example for 2 threads, 3 logs each: (3+1)*2 = 8 SRL groups

-- For Thread 1 (Node1):
ALTER DATABASE ADD STANDBY LOGFILE THREAD 1 GROUP 11 ('+DATA') SIZE 512M;
ALTER DATABASE ADD STANDBY LOGFILE THREAD 1 GROUP 12 ('+DATA') SIZE 512M;
ALTER DATABASE ADD STANDBY LOGFILE THREAD 1 GROUP 13 ('+DATA') SIZE 512M;
ALTER DATABASE ADD STANDBY LOGFILE THREAD 1 GROUP 14 ('+DATA') SIZE 512M;

-- For Thread 2 (Node2):
ALTER DATABASE ADD STANDBY LOGFILE THREAD 2 GROUP 15 ('+DATA') SIZE 512M;
ALTER DATABASE ADD STANDBY LOGFILE THREAD 2 GROUP 16 ('+DATA') SIZE 512M;
ALTER DATABASE ADD STANDBY LOGFILE THREAD 2 GROUP 17 ('+DATA') SIZE 512M;
ALTER DATABASE ADD STANDBY LOGFILE THREAD 2 GROUP 18 ('+DATA') SIZE 512M;

-- Verify
SELECT group#, thread#, sequence#, bytes/1024/1024 MB, status 
FROM v$standby_log
ORDER BY thread#, group#;
```

### **2.3 Configure Primary Database Parameters**
```sql
-- Set Data Guard specific parameters
-- Replace 'ORCL' with your database name

ALTER SYSTEM SET db_unique_name='ORCL_PRIMARY' SCOPE=SPFILE SID='*';
ALTER SYSTEM SET log_archive_config='dg_config=(ORCL_PRIMARY,ORCL_STANDBY)' SCOPE=SPFILE SID='*';
ALTER SYSTEM SET log_archive_dest_1='LOCATION=USE_DB_RECOVERY_FILE_DEST VALID_FOR=(ALL_LOGFILES,ALL_ROLES) DB_UNIQUE_NAME=ORCL_PRIMARY' SCOPE=SPFILE SID='*';
ALTER SYSTEM SET log_archive_dest_2='SERVICE=ORCL_STANDBY ASYNC VALID_FOR=(ONLINE_LOGFILES,PRIMARY_ROLE) DB_UNIQUE_NAME=ORCL_STANDBY' SCOPE=SPFILE SID='*';
ALTER SYSTEM SET log_archive_dest_state_2='ENABLE' SCOPE=SPFILE SID='*';
ALTER SYSTEM SET fal_server='ORCL_STANDBY' SCOPE=SPFILE SID='*';
ALTER SYSTEM SET fal_client='ORCL_PRIMARY' SCOPE=SPFILE SID='*';
ALTER SYSTEM SET standby_file_management='AUTO' SCOPE=SPFILE SID='*';

-- Enable flashback (highly recommended for fast failover)
ALTER SYSTEM SET db_recovery_file_dest_size=100G SCOPE=SPFILE SID='*';
ALTER SYSTEM SET db_recovery_file_dest='+RECO' SCOPE=SPFILE SID='*';

-- Restart database to apply changes
SHUTDOWN IMMEDIATE;
STARTUP;

-- Enable flashback
ALTER DATABASE FLASHBACK ON;

-- Verify parameters
SHOW PARAMETER db_unique_name;
SHOW PARAMETER log_archive_config;
SHOW PARAMETER log_archive_dest_2;
```

### **2.4 Configure TNSNAMES on Primary**
```bash
# On BOTH RAC nodes, edit tnsnames.ora
sudo vi $ORACLE_HOME/network/admin/tnsnames.ora

# Add this entry:
ORCL_STANDBY =
  (DESCRIPTION =
    (ADDRESS = (PROTOCOL = TCP)(HOST = stdbysvr)(PORT = 1521))
    (CONNECT_DATA =
      (SERVER = DEDICATED)
      (SERVICE_NAME = ORCL)
    )
  )

# Test connection from primary to standby (will fail until standby is setup)
tnsping ORCL_STANDBY
```

### **2.5 Create Password File for Standby**
```bash
# On primary, create password file for standby
orapwd file=$ORACLE_HOME/dbs/orapwORCL_STANDBY password=YourPassword123 entries=10

# Copy to standby server
scp $ORACLE_HOME/dbs/orapwORCL_STANDBY oracle@stdbysvr:$ORACLE_HOME/dbs/
```

## **PHASE 3: STANDBY SERVER SETUP**

### **3.1 Install Oracle Software Only**
```bash
# On standby server:
# 1. Install Oracle 21c software ONLY (no database)
# Run Oracle Universal Installer with "Install database software only"

# 2. Create oracle directories
mkdir -p /u01/app/oracle/oradata/ORCL
mkdir -p /u01/app/oracle/fast_recovery_area/ORCL
mkdir -p /u01/app/oracle/admin/ORCL/adump

# 3. Set environment variables
cat >> ~oracle/.bash_profile << 'EOF'
export ORACLE_SID=ORCL
export ORACLE_BASE=/u01/app/oracle
export ORACLE_HOME=/u01/app/oracle/product/21.0.0/dbhome_1
export PATH=$ORACLE_HOME/bin:$PATH
export LD_LIBRARY_PATH=$ORACLE_HOME/lib:$LD_LIBRARY_PATH
EOF

source ~oracle/.bash_profile
```

### **3.2 Configure Network on Standby**
```bash
# Create listener.ora
cat > $ORACLE_HOME/network/admin/listener.ora << 'EOF'
LISTENER =
  (DESCRIPTION_LIST =
    (DESCRIPTION =
      (ADDRESS = (PROTOCOL = TCP)(HOST = stdbysvr)(PORT = 1521))
      (ADDRESS = (PROTOCOL = IPC)(KEY = EXTPROC1521))
    )
  )

SID_LIST_LISTENER =
  (SID_LIST =
    (SID_DESC =
      (GLOBAL_DBNAME = ORCL)
      (ORACLE_HOME = /u01/app/oracle/product/21.0.0/dbhome_1)
      (SID_NAME = ORCL)
    )
  )
EOF

# Create tnsnames.ora
cat > $ORACLE_HOME/network/admin/tnsnames.ora << 'EOF'
ORCL_PRIMARY =
  (DESCRIPTION =
    (ADDRESS = (PROTOCOL = TCP)(HOST = rac-scan.cluster.local)(PORT = 1521))
    (CONNECT_DATA =
      (SERVER = DEDICATED)
      (SERVICE_NAME = ORCL)
    )
  )

ORCL_STANDBY =
  (DESCRIPTION =
    (ADDRESS = (PROTOCOL = TCP)(HOST = stdbysvr)(PORT = 1521))
    (CONNECT_DATA =
      (SERVER = DEDICATED)
      (SID = ORCL)
    )
  )
EOF

# Start listener
lsnrctl start
lsnrctl status
```

## **PHASE 4: CREATE STANDBY DATABASE USING RMAN DUPLICATE**

### **4.1 Create Initialization Parameter File for Standby**
```bash
# On primary, create pfile for standby
sqlplus / as sysdba

CREATE PFILE='/tmp/initORCL_standby.ora' FROM SPFILE;

# Copy to standby
scp /tmp/initORCL_standby.ora oracle@stdbysvr:/tmp/
```

### **4.2 Modify Standby Pfile**
```bash
# On standby server, edit the pfile
vi /tmp/initORCL_standby.ora

# Change these parameters:
*.db_unique_name='ORCL_STANDBY'
*.log_archive_config='dg_config=(ORCL_PRIMARY,ORCL_STANDBY)'
*.log_archive_dest_1='LOCATION=USE_DB_RECOVERY_FILE_DEST VALID_FOR=(ALL_LOGFILES,ALL_ROLES) DB_UNIQUE_NAME=ORCL_STANDBY'
*.log_archive_dest_2='SERVICE=ORCL_PRIMARY ASYNC VALID_FOR=(ONLINE_LOGFILES,PRIMARY_ROLE) DB_UNIQUE_NAME=ORCL_PRIMARY'
*.fal_server='ORCL_PRIMARY'
*.fal_client='ORCL_STANDBY'
*.standby_file_management='AUTO'
*.db_file_name_convert='+DATA/ORCL/','/u01/app/oracle/oradata/ORCL/','+DATA/ORCL/','/u01/app/oracle/oradata/ORCL/'
*.log_file_name_convert='+DATA/ORCL/','/u01/app/oracle/oradata/ORCL/','+DATA/ORCL/','/u01/app/oracle/oradata/ORCL/'
*.db_recovery_file_dest='/u01/app/oracle/fast_recovery_area'
*.db_recovery_file_dest_size=100G
```

### **4.3 Start Standby Instance in NOMOUNT**
```bash
# On standby server
export ORACLE_SID=ORCL
sqlplus / as sysdba

STARTUP NOMOUNT PFILE='/tmp/initORCL_standby.ora';
```

### **4.4 Use RMAN to Create Standby Database**
```bash
# Method 1: Active Duplicate (Recommended - No backup needed)
# On standby server, open another terminal:

# Set TNS_ADMIN if needed
export TNS_ADMIN=$ORACLE_HOME/network/admin

rman target sys/YourPassword@ORCL_PRIMARY auxiliary /

RMAN> DUPLICATE TARGET DATABASE FOR STANDBY FROM ACTIVE DATABASE
      NOFILENAMECHECK
      SPFILE
      SET db_unique_name='ORCL_STANDBY'
      SET log_archive_dest_2='SERVICE=ORCL_PRIMARY ASYNC VALID_FOR=(ONLINE_LOGFILES,PRIMARY_ROLE) DB_UNIQUE_NAME=ORCL_PRIMARY'
      SET fal_server='ORCL_PRIMARY'
      SET fal_client='ORCL_STANDBY'
      SET standby_file_management='AUTO';

# This will take time depending on database size
# Monitor progress in RMAN output
```

### **4.5 Alternative: Backup/Restore Method (if active duplicate fails)**
```bash
# On primary, create RMAN backup for standby
rman target /

RMAN> BACKUP DATABASE PLUS ARCHIVELOG;
RMAN> BACKUP CURRENT CONTROLFILE FOR STANDBY;

# Copy backups to standby
# Then on standby:
rman target sys/YourPassword@ORCL_PRIMARY auxiliary sys/YourPassword@ORCL_STANDBY

RMAN> DUPLICATE TARGET DATABASE FOR STANDBY;
```

## **PHASE 5: START REDO APPLY ON STANDBY**

### **5.1 Mount Standby Database and Start MRP**
```sql
-- On standby server
sqlplus / as sysdba

-- Mount standby database
ALTER DATABASE MOUNT STANDBY DATABASE;

-- Start Managed Recovery Process (MRP)
ALTER DATABASE RECOVER MANAGED STANDBY DATABASE 
  USING CURRENT LOGFILE 
  DISCONNECT FROM SESSION;

-- Check recovery status
SELECT PROCESS, STATUS, THREAD#, SEQUENCE#, BLOCK# 
FROM V$MANAGED_STANDBY;
```

### **5.2 Verify Data Guard Status**
```sql
-- On standby, check if redo is being applied
SELECT ARCHIVED_THREAD#, ARCHIVED_SEQ#, APPLIED_THREAD#, APPLIED_SEQ# 
FROM V$ARCHIVE_DEST_STATUS 
WHERE DEST_ID=2;

-- Check for gaps
SELECT THREAD#, LOW_SEQUENCE#, HIGH_SEQUENCE# 
FROM V$ARCHIVE_GAP;

-- On primary, force log switch and check
ALTER SYSTEM SWITCH LOGFILE;
ALTER SYSTEM ARCHIVE LOG CURRENT;
```

## **PHASE 6: CONFIGURE DATA GUARD BROKER**

### **6.1 Enable Broker on Both Databases**
```sql
-- On primary (from any RAC node)
ALTER SYSTEM SET dg_broker_start=TRUE SCOPE=BOTH SID='*';
ALTER SYSTEM SET dg_broker_config_file1='+DATA/orcl/dr1ORCL.dat' SCOPE=BOTH SID='*';
ALTER SYSTEM SET dg_broker_config_file2='+RECO/orcl/dr2ORCL.dat' SCOPE=BOTH SID='*';

-- On standby
ALTER SYSTEM SET dg_broker_start=TRUE;
ALTER SYSTEM SET dg_broker_config_file1='/u01/app/oracle/oradata/ORCL/dr1ORCL.dat';
ALTER SYSTEM SET dg_broker_config_file2='/u01/app/oracle/fast_recovery_area/ORCL/dr2ORCL.dat';
```

### **6.2 Create Broker Configuration**
```bash
# Connect to broker from primary
dgmgrl sys/YourPassword@ORCL_PRIMARY

# Create configuration
DGMGRL> CREATE CONFIGURATION 'DG_ORCL' AS
       PRIMARY DATABASE IS 'ORCL_PRIMARY'
       CONNECT IDENTIFIER IS ORCL_PRIMARY;

DGMGRL> ADD DATABASE 'ORCL_STANDBY' AS
       CONNECT IDENTIFIER IS ORCL_STANDBY
       MAINTAINED AS PHYSICAL;

DGMGRL> ENABLE CONFIGURATION;

# Verify
DGMGRL> SHOW CONFIGURATION;
DGMGRL> SHOW DATABASE VERBOSE 'ORCL_PRIMARY';
DGMGRL> SHOW DATABASE VERBOSE 'ORCL_STANDBY';
```

## **PHASE 8: MONITORING SCRIPTS**

### **8.1 Create Monitoring Script**
```bash
# Create script /home/oracle/monitor_dg.sh
cat > /home/oracle/monitor_dg.sh << 'EOF'
#!/bin/bash
echo "=== Data Guard Status: $(date) ==="
echo ""

# Check primary status
echo "1. Primary Database Status:"
sqlplus -s / as sysdba << SQL
SET PAGES 0 FEED OFF
SELECT 'Primary: ' || name || ', Role: ' || database_role || ', Log Mode: ' || log_mode 
FROM v\$database;
SQL

echo ""
echo "2. Archive Destinations:"
sqlplus -s / as sysdba << SQL
SET PAGES 100 LINES 200
COL DEST_NAME FOR A25
COL STATUS FOR A15
COL ERROR FOR A30
SELECT dest_id, dest_name, status, error, destination 
FROM v\$archive_dest 
WHERE status != 'INACTIVE'
ORDER BY dest_id;
SQL

echo ""
echo "3. Transport Lag:"
sqlplus -s / as sysdba << SQL
SET PAGES 0 FEED OFF
SELECT 'Transport Lag: ' || value 
FROM v\$datagaurd_stats 
WHERE name = 'transport lag';
SQL

echo ""
echo "4. Standby Apply Status:"
sqlplus -s / as sysdba << SQL
SET PAGES 0 FEED OFF
SELECT 'Applied Seq#: ' || applied_seq# || ', Received Seq#: ' || received_seq# 
FROM v\$archive_dest_status 
WHERE dest_id = 2;
SQL
EOF

chmod +x /home/oracle/monitor_dg.sh
```

### **8.2 Simple Data Guard Health Check**
```sql
-- Run this on primary
SET LINES 200 PAGES 1000
COL NAME FOR A30
COL VALUE FOR A50

-- Overall status
SELECT name, database_role, db_unique_name, open_mode, 
       protection_mode, protection_level, switchover_status
FROM v$database;

-- Archive destinations
SELECT dest_id, dest_name, status, error, destination, 
       archived_thread#, archived_seq#, applied_thread#, applied_seq#
FROM v$archive_dest_status
WHERE status != 'INACTIVE';

-- Redo transport status
SELECT name, value, unit FROM v$dataguard_stats;

-- Gap status
SELECT * FROM v$archive_gap;
```

## **PHASE 9: TROUBLESHOOTING COMMON ISSUES**

### **9.1 Common Problems & Solutions**
```sql
-- 1. ORA-12514: TNS:listener does not currently know of service requested
-- Solution: Check listener.ora and tnsnames.ora on both sides
-- On standby: lsnrctl status

-- 2. ORA-1031: Insufficient privileges
-- Solution: Copy password file from primary to standby
-- Make sure SYS password is same on both sides

-- 3. Archive log gaps
-- On standby:
ALTER DATABASE RECOVER MANAGED STANDBY DATABASE CANCEL;
ALTER DATABASE RECOVER MANAGED STANDBY DATABASE DISCONNECT FROM SESSION;

-- 4. Standby not applying logs
-- Check MRP process:
SELECT PROCESS, STATUS, THREAD#, SEQUENCE#, BLOCK# 
FROM V$MANAGED_STANDBY;

-- If not running:
ALTER DATABASE RECOVER MANAGED STANDBY DATABASE DISCONNECT FROM SESSION;

-- 5. Network timeouts
-- Increase NET_TIMEOUT:
ALTER SYSTEM SET log_archive_dest_2='SERVICE=ORCL_STANDBY ASYNC NET_TIMEOUT=60 ...';
```

### **9.2 Reset Data Guard if Something Goes Wrong**
```bash
# If you need to start over:

# 1. On standby:
sqlplus / as sysdba
SHUTDOWN IMMEDIATE;
STARTUP MOUNT;
ALTER DATABASE RECOVER MANAGED STANDBY DATABASE CANCEL;
ALTER DATABASE ACTIVATE STANDBY DATABASE;
SHUTDOWN IMMEDIATE;
STARTUP MOUNT;
ALTER DATABASE FLASHBACK OFF;
DROP DATABASE;

# 2. On primary:
ALTER SYSTEM SET log_archive_dest_state_2='DEFER';

# 3. Start again from Phase 4
```

## **PHASE 10: AUTOMATION & MAINTENANCE**

### **10.1 Backup Script for Data Guard**
```bash
# Create backup script /home/oracle/backup_dg.sh
cat > /home/oracle/backup_dg.sh << 'EOF'
#!/bin/bash
export ORACLE_SID=ORCL
export ORACLE_HOME=/u01/app/oracle/product/21.0.0/dbhome_1
export NLS_DATE_FORMAT="YYYY-MM-DD HH24:MI:SS"

LOG_FILE="/home/oracle/backup_dg_$(date +%Y%m%d).log"

rman target / log=$LOG_FILE << RMAN_EOF
RUN {
  # Backup database
  BACKUP DATABASE PLUS ARCHIVELOG;
  
  # Crosscheck and delete obsolete backups
  CROSSCHECK BACKUP;
  DELETE NOPROMPT OBSOLETE;
  
  # Backup controlfile
  BACKUP CURRENT CONTROLFILE;
}
RMAN_EOF

echo "Backup completed. Log: $LOG_FILE"
EOF

chmod +x /home/oracle/backup_dg.sh
```
